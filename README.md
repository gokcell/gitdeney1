# Git Deney Projem

Bu proje, Git ve Jules AI testleri için hazırlanmış deneysel bir depodur.

## Proje İçeriği

- `README.md`: Proje hakkında bilgilendirme ve kullanım kılavuzu.
- `yolla.sh`: Değişiklikleri otomatik olarak ekleyen (`git add`), commit eden (`git commit`) ve uzak depoya gönderen (`git push`) yardımcı bir Bash betiği.

## Kullanım

`yolla.sh` betiğini çalıştırmak için aşağıdaki komutu kullanabilirsiniz:

```bash
./yolla.sh "Yapılan değişikliklerin özeti"
```
